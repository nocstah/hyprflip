# Beta invitation draft

I'm looking for a few Omarchy users on the default dwindle layout to try
Hyprflip: related apps become the front and back of one desktop card. For
example, Gmail on the front and WhatsApp + Telegram on the back. Flip between
them, unfold both sides, or save the arrangement and reopen it later.

The new preview works with the core plugin on dwindle—hy3 is optional. It also
fits unfolded faces to their apps' size requirements, which fixes the Comms
example on my laptop. This preview targets Hyprland 0.56.2.

I'm especially interested in whether installation is straightforward on a
stock setup, whether the controls are clear, and whether saved cards reopen
reliably. A short trial with three terminal windows is enough to help.
